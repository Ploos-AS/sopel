# Sopel container v0.1.0

Initial Ploos AS container release for Sopel.

## Included

- Sopel `8.0.4` pinned to upstream release commit `78e4a32bd63a2f220cdae3ac069584507e8ae9a1`
- Python 3.12 slim-bookworm runtime
- non-root UID/GID 1000
- persistent `/data` configuration and state directory
- first-run configuration wizard workflow
- explicit config selection with `SOPEL_CONFIG`
- `SOPEL_CONFIG_DIR=/data`
- `tini` PID 1
- strict runtime healthcheck
- Docker Compose example
- rootless Podman Quadlet example
- `linux/amd64` and `linux/arm64` publication workflow
- GHCR tags for edge, semver and latest releases
- SBOM and provenance attestations from BuildKit publishing
- MIT packaging license with upstream EFL-2.0 attribution

## Image

`ghcr.io/ploos-as/sopel:0.1.0`

The release tag is promoted only after the edge build, static validation, image build, and smoke tests pass.
